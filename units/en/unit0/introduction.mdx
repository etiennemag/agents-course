## À quoi s'attendre avec ce cours ? [[expect]]

Dans ce cours, vous allez :

- 📖 Étudier les agents IA en **théorie, conception et pratique.**
- 🧑‍💻 Apprendre à **utiliser des bibliothèques d'agents IA établies**, comme [smolagents](https://huggingface.co/docs/smolagents/en/index), [LangChain](https://www.langchain.com/) et [LlamaIndex](https://www.llamaindex.ai/).
- 💾 **Partager vos agents** sur le Hugging Face Hub et explorer les agents créés par la communauté.
- 🏆 Participer à des défis où vous pourrez **évaluer vos agents face à ceux d'autres étudiants**.
- 🎓 **Obtenir un certificat de réussite** en complétant les activités.

Et bien plus encore !

À la fin de ce cours, vous comprendrez **comment fonctionnent les agents et comment créer vos propres agents en utilisant les bibliothèques et outils les plus récents**.

## À quoi ressemble le cours ? [[course-look-like]]

Le cours se compose de :

- *Unités fondamentales* : où vous apprenez les **concepts théoriques des agents**.
- *Pratique* : où vous apprenez à **utiliser des bibliothèques établies d'agents IA** pour former vos agents dans des environnements spécifiques. Ces sections pratiques se dérouleront dans **les Spaces de Hugging Face** avec un environnement préconfiguré.
- *Missions pratiques* : où vous appliquerez les concepts appris pour résoudre un problème réel de votre choix.
- *Le Défi* : où vous mettrez votre agent en compétition avec d'autres agents dans un défi. Un [tableau de classement](https://huggingface.co/spaces/huggingface-projects/AI-Agents-Leaderboard) (non encore disponible) vous permettra de comparer les performances des agents.

Ce **cours est un projet vivant, évoluant grâce à vos retours et contributions !** N'hésitez pas à [ouvrir des tickets et pull requests sur GitHub](https://github.com/huggingface/agents-course), et à participer aux discussions sur notre serveur Discord.

Après avoir suivi le cours, vous pouvez également envoyer vos retours [👉 à l'aide de ce formulaire](https://docs.google.com/forms/d/e/1FAIpQLSe9VaONn0eglax0uTwi29rIn4tM7H2sYmmybmG5jJNlE5v0xA/viewform?usp=dialog)

## Quel est le programme ? [[syllabus]]

Voici le **programme général du cours**. Une liste détaillée des sujets sera publiée avec chaque unité.

| Chapitre | Sujet | Description |
| :---- | :---- | :---- |
| 0 | Introduction | Familiarisez-vous avec les outils et plateformes nécessaires. |
| 1 | Fondamentaux des agents | Découvrez les outils, pensées, actions, observations, et leurs formats. Préparez-vous aux LLMs, messages, tokens spéciaux, et templates de conversation. Voyez un cas simple avec des fonctions Python comme outils. |
| 2 | Frameworks | Comprenez comment les principes de base sont implémentés dans les bibliothèques populaires : smolagents, LangGraph, LlamaIndex |
| 3 | Cas pratiques | Construisez des cas d'utilisation réels (ouvert aux PRs 🤗 des créateurs expérimentés d'agents) |
| 4 | Projet final | Créez un agent pour un benchmark choisi et démontrez vos acquis sur le tableau de classement 🚀 |

*Des unités bonus sont également prévues. Restez à l'écoute !*

## Le processus de certification [[certification-process]]

<img src="https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/unit0/three-paths.jpg" alt="Deux parcours" width="100%"/>

Vous pouvez choisir de suivre ce cours en *mode audit* ou réaliser les activités pour **obtenir un des deux certificats proposés**.

Le processus de certification est **entièrement gratuit** :

- *Pour obtenir une certification des fondamentaux* : terminez l'Unité 1. Idéal pour les apprenants souhaitant découvrir les agents IA.
- *Pour obtenir un certificat de réussite* : complétez l'Unité 1, une mission pratique et le défi final.

Date limite : toutes les activités doivent être terminées avant **le 1er mai 2025**.
