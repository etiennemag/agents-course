# Onboarding : Vos premiers pas ⛵

<img src="https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/unit0/time-to-onboard.jpg" alt="Time to Onboard" width="100%"/>

Maintenant que vous avez tous les détails, commençons ! Nous allons faire quatre choses :

1. **Créer votre compte Hugging Face** si ce n’est pas déjà fait
2. **Vous inscrire sur Discord et vous présenter** (n’ayez pas peur 🤗)
3. **Suivre le Hugging Face Agents Course** sur le Hub
4. **Faire connaître** le cours

### Étape 1 : Créez votre compte Hugging Face

(Si vous ne l’avez pas déjà fait) créez un compte Hugging Face <a href='https://huggingface.co/join' target='_blank'>ici</a>.

### Étape 2 : Rejoignez notre communauté Discord

👉🏻 Rejoignez notre serveur Discord <a href="https://discord.gg/UrrTSsSyjb" target="_blank">ici.</a>

Lorsque vous arrivez, n’oubliez pas de vous présenter dans le salon `#introduce-yourself`.

Nous avons plusieurs canaux dédiés aux AI Agents :
- `agents-course-announcements` : pour les **dernières informations sur le cours**.
- `🎓-agents-course-general` : pour les **discussions générales et papotages**.
- `agents-course-questions` : pour **poser des questions et aider vos camarades**.
- `agents-course-showcase` : pour **présenter vos meilleurs agents**.

Vous pouvez également consulter :

- `smolagents` : pour **discuter et obtenir de l'aide sur la bibliothèque**.

Si c’est la première fois que vous utilisez Discord, nous avons rédigé un « Discord 101 » pour adopter les bonnes pratiques. Consultez [la section suivante](discord101).

### Étape 3 : Suivez l’organisation Hugging Face Agents Course

Restez informé des derniers documents du cours, des mises à jour et des annonces **en suivant l’organisation Hugging Face Agents Course**.

👉 Rendez-vous <a href="https://huggingface.co/agents-course" target="_blank">ici</a> et cliquez sur **Follow**.

<img src="https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/communication/hf_course_follow.gif" alt="Follow" width="100%"/>

### Étape 4 : Faites connaître le cours

Aidez-nous à rendre ce cours plus visible ! Il y a deux façons de nous aider :

1. Montrez votre soutien en mettant une ⭐ sur <a href="https://github.com/huggingface/agents-course" target="_blank">le dépôt du cours</a>.

<img src="https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/communication/please_star.gif" alt="Repo star"/>

2. Partagez votre parcours d’apprentissage : **dites à tout le monde** que vous suivez ce cours ! Nous avons préparé une illustration que vous pouvez utiliser dans vos publications sur les réseaux sociaux

<img src="https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/communication/share.png">

Vous pouvez télécharger l’image en cliquant 👉 [ici](https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/communication/share.png?download=true)

Félicitations ! 🎉 **Vous avez terminé le processus d’onboarding** ! Vous êtes maintenant prêt(e) à commencer à apprendre sur les Agents IA. Amusez-vous bien !

Continuez à apprendre, restez formidables 🤗
